# SavBlogs

SavBlogs is now a Next.js app backed by Firebase Auth, Firestore, Storage, and a Next route handler for admin role management.

## Setup

```bash
npm install
cp .env.local.example .env.local
```

Fill in the Firebase values in `.env.local`.

## Development

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
